Inferia LLM follows a structured monorepo pattern to separate executable applications from reusable core libraries.

## Top-Level Directories

| Directory | Description |
| :--- | :--- |
| **`apps/`** | Frontend Applications (Dashboard, Documentation). |
| **`package/`** | The public Python package (`inferia`) containing all core logic, services, and gateways. |
| **`deploy/`** | Infrastructure-as-Code (Docker Compose, Kubernetes manifests). |

## 1. Apps (`apps/`)

These are the frontend user interfaces.

-   **`dashboard/`**: React (Vite) frontend for the management console.
-   **`docs/`**: This documentation site (built with Next.js).

## 2. Package (`package/`)

This directory contains the source code for the `inferia` Python package. **All backend logic lives here.**

-   **`src/inferia/services/`**:
    -   `inference/`: High-performance proxy for API requests.
    -   `api_gateway/`: Authentication, RBAC, and policy enforcement.
        - `rbac/`: Auth router, roles, users management.
        - `gateway/`: Internal routes, proxy routes to orchestration.
        - `management/`: Organization, deployment, API key, config management.
        - `audit/`: Audit log router with category filtering.
        - `policy/`: Quota, rate limit, and budget enforcement.
        - `prompt/`: Prompt template management.
    -   `guardrail/`: Content safety scanning and PII detection.
    -   `data/`: Knowledge base management, RAG, vector operations, prompt processing.
    -   `orchestration/`: Control plane for compute pools and deployments.
        - `services/depin-sidecar/`: Node.js sidecar for Nosana/Akash DePIN interactions.
-   **`src/inferia/cli.py`**: The `inferia` command-line interface entry point.
-   **`src/inferia/infra/schema/`**: Database schema and migrations.
    - `global_schema.sql`: Main database schema.
    - `migrations/`: Incremental migration files.
-   **`src/inferia/dashboard/`**: Pre-built React dashboard assets (generated by `inferiallm init --env dev`).

## 3. Deploy (`deploy/`)

-   **`docker-compose.yml`**: Definition for running the entire stack locally. Supports `--profile unified` (monolith) and `--profile split` (microservices) modes.
-   **`Dockerfile`**: Unified Docker image for all services.
-   **`.env`**: Centralized environment configuration.
