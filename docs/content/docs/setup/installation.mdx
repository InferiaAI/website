This guide provides detailed instructions for installing and configuring Inferia LLM.

## System Requirements

| Component | Requirement | Description |
| :--- | :--- | :--- |
| **OS** | Linux / macOS | Windows supported via WSL2 |
| **Python** | 3.10+ | Core runtime for all services |
| **Node.js** | 18+ | Required for Dashboard and DePIN Sidecars |
| **PostgreSQL** | 14+ | Primary database |
| **Redis** | 6+ | Rate limiting and task queues |

## 1. Environment Configuration

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/InferiaAI/InferiaLLM.git
    cd InferiaLLM
    ```

2.  **Initialize Configuration**:
    ```bash
    cp .env.sample .env
    ```

3.  **Edit `.env`**:
    
    **Required Variables:**
    | Variable | Description |
    | --- | --- |
    | `DATABASE_URL` | PostgreSQL connection string |
    | `REDIS_HOST` | Redis hostname (default: `localhost`) |
    | `JWT_SECRET_KEY` | JWT signing secret |
    | `INTERNAL_API_KEY` | Service-to-service auth |
    | `SECRET_ENCRYPTION_KEY` | Credential encryption key |
    | `SUPERADMIN_EMAIL` | Initial admin email |
    | `SUPERADMIN_PASSWORD` | Initial admin password |

## 2. Option A: Python Package (Recommended)

### Standard Installation
```bash
pip install inferiallm==0.1.0b1
```

### Developer Installation
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e package/
```

### Database Initialization
```bash
inferiallm init
```

### Start Services
```bash
# Start all services
inferiallm start

# Or start specific services
inferiallm start orchestration  # Orchestration Gateway + Worker + DePIN Sidecar + SkyPilot
inferiallm start inference      # Inference Gateway
inferiallm start api-gateway    # API Gateway
inferiallm start guardrail      # Guardrail Engine
inferiallm start data           # Data Engine
inferiallm start skypilot       # SkyPilot API Server
```

---

## 3. Option B: Docker

### 1. Pull Image and Configure Environment

```bash
docker pull inferiaai/inferiallm:v0.1.0-beta.1
curl -L https://raw.githubusercontent.com/InferiaAI/InferiaLLM/main/.env.sample -o .env
nano .env
```

### 2. Run the Container

```bash
docker run -d \
  --name inferia-app \
  --env-file .env \
  -p 8000:8000 -p 8001:8001 -p 8002:8002 -p 8003:8003 -p 8080:8080 -p 3000:3000 -p 3001:3001 \
  inferiaai/inferiallm:v0.1.0-beta.1
```

## CLI Commands

| Command | Description |
| --- | --- |
| `inferiallm init` | Initialize database, roles, schemas, and admin user |
| `inferiallm migrate` | Apply pending database migrations after upgrades |
| `inferiallm start` | Start all services |
| `inferiallm start orchestration` | Start Orchestration Gateway + Worker + DePIN Sidecar + SkyPilot |
| `inferiallm start inference` | Start Inference Gateway |
| `inferiallm start api-gateway` | Start API Gateway |
| `inferiallm start guardrail` | Start Guardrail Engine |
| `inferiallm start data` | Start Data Engine |
| `inferiallm start skypilot` | Start SkyPilot API Server |
