## Installation

```bash
pip install inferiallm==0.1.0b1
```

## CLI Reference

The `inferiallm` package comes with a built-in CLI for managing the entire platform.

```bash
usage: inferiallm [-h] {init,migrate,start} ...
```

### Commands

#### `inferiallm init`
Initializes the database schema, creates roles, and sets up the initial admin user.

- **Usage**: `inferiallm init`
- **Options**: `--env dev` to rebuild dashboard and sidecar assets
- **Requires**: Valid `DATABASE_URL` in `.env`

#### `inferiallm migrate`
Applies pending database migrations to an existing database. Run after upgrading to a new version.

- **Usage**: `inferiallm migrate`
- Automatically discovers and applies unrun `.sql` migration files

#### `inferiallm start`
Starts all services (API Gateway, Inference, Orchestration, Guardrail Engine, Data Engine, Dashboard).

- **Usage**: `inferiallm start [service]`
- **Options**:
  - No arguments / `all`: Starts all services
  - `orchestration`: Start Orchestration Gateway + Worker + DePIN Sidecar + SkyPilot
  - `inference`: Start Inference Gateway
  - `api-gateway`: Start API Gateway
  - `guardrail`: Start Guardrail Engine
  - `data`: Start Data Engine
  - `skypilot`: Start SkyPilot API Server

**Examples:**
```bash
# Start all services
inferiallm start

# Start specific services
inferiallm start orchestration
inferiallm start inference
inferiallm start api-gateway
inferiallm start guardrail
inferiallm start data
```

### Service Ports

| Service | Default Port |
| --- | --- |
| API Gateway | 8000 |
| Inference Gateway | 8001 |
| Guardrail Engine | 8002 |
| Data Engine | 8003 |
| Orchestration Gateway | 8080 |
| DePIN Sidecar | 3000 |
| Dashboard | 3001 |

## Using the OpenAI SDK

Since InferiaLLM provides an OpenAI-compatible API, you can use the standard OpenAI Python SDK:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="sk-inferia-..."  # Your API key from Dashboard
)

response = client.chat.completions.create(
    model="my-deployment-name",  # Use your Deployment Name
    messages=[
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

## Streaming

```python
response = client.chat.completions.create(
    model="my-deployment-name",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
```
