## What is Inferia LLM?

import InstallTabs from "@/components/landing/InstallTabs";

**Inferia LLM** is the **operating system for LLMs in production**. It acts as the authoritative execution layer between your applications and your AI infrastructure — governing how LLMs are accessed, secured, routed, and run on compute.

InferiaLLM provides platform-level primitives as a single, cohesive system: execution entry points, access control, safety enforcement, resource limits, scheduling and routing, compute lifecycle management, and auditing.

## System Components

Inferia consists of six core services:

1.  **[Inference Gateway](/docs/api-reference/inference-gateway)**: Data-plane ingress for all LLM inference traffic.
2.  **[API Gateway](/docs/api-reference/filtration-gateway)**: Authentication, RBAC, policy enforcement, and quota management.
3.  **[Orchestration Gateway](/docs/api-reference/orchestration-gateway)**: Compute control authority and execution routing.
4.  **Guardrail Engine**: Content safety scanning, PII detection, and prompt injection protection.
5.  **Data Engine**: Knowledge base management, document ingestion, and vector operations.
6.  **Admin Dashboard**: Administrative control surface for policies, compute pools, usage, and audits.
