## Overview

InferiaLLM is the operating system for LLMs in production. It acts as the authoritative execution layer between your applications and your AI infrastructure — governing how LLMs are accessed, secured, routed, and run on compute.

InferiaLLM provides platform-level primitives as a single, cohesive system: execution entry points, access control and permissions, safety enforcement, resource limits and cost controls, scheduling and routing, compute lifecycle management, and auditing and observability.

## Key Features

- **Unified Interface**: OpenAI-compatible endpoints for seamless integration with existing tools and libraries
- **Security First**: Built-in Guardrail Engine provides PII redaction, prompt injection protection, and content safety scanning
- **Orchestration**: Intelligent routing and job management across diverse compute pools (Kubernetes, SkyPilot, Nosana, Akash)
- **Observability**: Comprehensive logging, Prometheus-compatible metrics, and structured audit logging
- **Multi-Provider**: Proxy requests to OpenAI, Anthropic, Gemini, Groq, Cerebras, Mistral, DeepSeek
- **Inference Engines**: Supports vLLM, Ollama, TEI, Infinity, LocalAI, Inferia Diffusion

## System Components

InferiaLLM consists of six core services:

1. **Inference Gateway**: Data-plane ingress for all LLM inference traffic (port 8001)
2. **API Gateway**: Authentication, RBAC, policy enforcement, and quota management (port 8000)
3. **Orchestration Gateway**: Compute control authority and execution routing (port 8080)
4. **Guardrail Engine**: Content safety scanning, PII detection, and prompt injection protection (port 8002)
5. **Data Engine**: Knowledge base management, document ingestion, and vector operations (port 8003)
6. **Admin Dashboard**: Administrative control surface for policies, compute pools, usage, and audits (port 3001)

## Technology Stack

- **Language**: Python 3.10+
- **API Framework**: FastAPI (Asynchronous, High-performance)
- **Inter-Service Communication**: gRPC (Protobuf)
- **Task Queue**: Redis Streams & Pub/Sub
- **Primary Database**: PostgreSQL 15
- **Cache & Broker**: Redis 7
- **Vector Query**: pgvector / ChromaDB
- **Authentication**: Stateless JWT (HS256)
- **Encryption**: Fernet (Symmetric encryption for secrets)

## Compute Providers

- **Nosana** — decentralized GPU compute (DePIN)
- **AWS** — EC2 GPU instances via SkyPilot
- **GCP** — Compute Engine via SkyPilot
- **Akash** — decentralized cloud (SDL-based)
- **Kubernetes** — on-prem / managed clusters
